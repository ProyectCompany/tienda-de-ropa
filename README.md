# Amélie Showroom SP ✨👗

Tienda online de moda femenina y kids para **Amélie Showroom SP** (Presidencia Roque Sáenz Peña, Chaco, Argentina).

Sitio web oficial interactivo, moderno y 100% responsivo con catálogo de prendas, selector de talles, carrito de compras y cotización/consulta de stock directa por WhatsApp.

---

## 🌟 Características

- **Catálogo de Colección:** 12 prendas organizadas con selector de talles y etiquetas exclusivas (*Nuevo*, *Amélie Kids*).
- **Vistas Interactivas con Hover:** Transición de fotos doble (en modelo y en plano *flat-lay* o detalles).
- **Filtros por Categoría:** *Todas las prendas*, *Colección Mujer* y *Amélie Kids*.
- **Consulta de Stock por WhatsApp:** Mensajes preformateados automáticos enviados al número oficial (`+54 9 364 473-3030`) con nombre de la prenda, talle seleccionado y enlace directo a la foto.
- **Carrito de Compras:** Añade múltiples artículos, actualiza cantidades y consulta el stock consolidado de todo el pedido por WhatsApp.
- **Buscador en Tiempo Real:** Búsqueda rápida por nombre o tipo de prenda.
- **100% Responsivo y Cross-Browser:** Adaptado para smartphones (iPhone, Android), tablets y computadoras, con soporte para Safe Areas y prevención de zoom en iOS Safari.

## 🚀 Cómo Ejecutar Localmente

No requiere dependencias externas pesadas.

1. Clona el repositorio:
   ```bash
   git clone https://github.com/ProyectCompany/tienda-de-ropa.git
   ```

2. Ingresa a la carpeta del proyecto y ejecuta el servidor local con Node.js:
   ```bash
   node scripts/local-server.js
   ```

3. Abre en tu navegador:
   ```
   http://localhost:3000
   ```
